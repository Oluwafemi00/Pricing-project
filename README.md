## How It Works

**No signup. No downloads. No complications.**

1. **Open it** - Works in any browser, phone, tablet, computer
2. **Convert** - Type an amount, pick currencies, see the result instantly
3. **Save favorites** - ★ the pairs you use often (USD/NGN, EUR/GBP, etc.)
4. **Check history** - Every conversion is saved. Back in 2 seconds
5. **Close it** - Come back later, everything's still there

That's it. No app installations. No account creation. Just currency conversion that works.

## The Technical Side (For Developers)

Built with:

- **No frameworks** - Pure JavaScript, works everywhere
- **No bloat** - 28KB total, loads instantly
- **No complications** - Single HTML file, copy-paste deployment
- **No servers needed** - Runs entirely in your browser
- **Offline-first design** - Works without internet
- **Live data** - Rates update every minute from ECB

It uses a free exchange rate API (Frankfurter) that sources data from the European Central Bank—the official, trusted source for exchange rates.

## What I Learned Building This

**User Psychology**

- Speed matters more than features
- People remember tools that just work
- Offline capability builds trust
- Favorites reduce friction on repeat tasks

**Product Design**

- What problem am I solving? (quick conversions, not trading)
- Who am I solving it for? (travelers, not day traders)
- What's the simplest solution? (converter, not charting platform)

**Real-World Constraints**

- Not everyone has fast internet (offline mode)
- Not everyone wants dark screens (light mode)
- Not everyone trades major currencies (150+ options)
